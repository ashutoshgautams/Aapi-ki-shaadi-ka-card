# Audio

Drop the ambient track here as `ambience.mp3`.

Wanted: 60–150 s, seamlessly loopable, ~128 kbps mono or stereo, under ~2 MB.
Something soft and instrumental — sitar, rubab, bansuri, or a slow nasheed
without heavy percussion. It plays at 38% volume under the whole page.

If this file is missing the music control removes itself; nothing breaks.
